# 股选优 v0.6.4

v0.6.4 更新 Rust 工具链与依赖，补强公司资料缓存、公开数据读取边界，以及 Windows 和 Android 的研究工作区交互。

## 更新内容

- Rust 最低版本提升至 1.100，三个 Rust 模块使用 resolver 3；发布构建启用 thin LTO、单个 codegen unit 和符号裁剪。
- 升级 Rig 0.46.0、rusqlite 0.42.0、calamine 0.38.0、lopdf 0.47.0、fastembed 7.7.0 与 encoding_rs 0.8.44；同步独立研究模块锁文件。
- 按实际用途收紧 PDF、HTTP、时间与嵌入依赖的默认特性；保留 TLS、代理、HTTP/2、JSON、上传及流式读取支持。Android 证书根依赖按目标平台启用，GEPA 继续作为可选实验特性并固定依赖版本。
- 公司资料按请求代次发布，较早响应不能覆盖较新资料；文件已替换但目录同步失败时保留新资料与重试提示，替换前失败仍允许后续有效保存。
- 公司资料缓存统一 256KiB 读写上限；公开数据在读取过程中执行 10MiB 上限，同时处理已知长度与分块响应。
- 补充 A 股公司业务资料与消息证据展示，改进桌面与移动端的搜索、工作区布局、键盘和返回操作。
- 更新 React 构建、图标和测试工具：Vite 8.3.8、React 插件 6.3.0、Vitest 5.1.0、lucide-react 1.72.0，以及相关类型声明。构建环境要求 Node.js 22.12+（22.x）或 24.x。

本次 Android ARM64 签名 APK 约 40.4MiB，较 v0.6.3 的 57.4MiB 减少约 30%。这是安装包体积比较，不代表设备运行性能提升。

## 本地验证

- 核心 128 项测试通过；8,000 只股票筛选样例连续运行 10 次，平均约 324ms，低于现有 500ms 门槛。
- 研究模块独立锁定测试 80 项通过；Tauri 默认与全部可选特性各 819 项通过、8 项显式忽略。公司资料 12 项回归包括“已替换但同步失败”和较早请求完成的错误路径。
- 三个 Rust 模块的格式与 Clippy 命令退出 0，Clippy 仍有既存警告；默认与可选特性编译检查通过。
- 前端 939 项单测、生产构建与入口包体积门槛通过；主入口 gzip 约 95KiB。npm 审计结果为 0 个已知漏洞。
- 完整视觉与交互门禁通过，包括 82 组消息截图、4 组研究助手截图、6 组回测状态、搜索／快捷键／消息操作，以及 24 组对比度检查。可靠性 fixture 与 Android 包名隔离、凭据资源生成检查通过；原有视觉基线与 0.1% 阈值保持不变。
- Windows 发布程序及 NSIS 安装包构建通过；Android ARM64 发布构建、包名、版本和签名核验通过。

## 浏览器工具兼容性

Playwright 固定在已验证的 1.64.1 / Chromium 156。评估 1.65 后确认其 Chromium 158 Headless Shell 的原生日期控件忽略区域设置，完整浏览器的像素渲染也与当前验收基线存在差异，因此这轮保留原有渲染环境与严格视觉阈值。回测截图增加实际 ISO 日期值检查及渲染信息记录。

## 已知边界

- adaptive 严格样本外门槛仍未获得完整点时数据验证，本版本不宣称该门槛已通过；缺少必要历史快照时仍会明确拒绝严格验证。
- 同设备启动、内存、后台请求与缓存性能基线未采集，相关性能门槛保持未评估。单个核心筛选样例不能替代设备性能验证。
- 新安装包尚未进行设备安装或升级验收；Windows 安装包 Authenticode 状态为 `NotSigned`。
