# 港股行情 MVP 设计（已被完整市场设计取代）

> 本文记录初始市场接入阶段的范围。产品目标已扩展为 README 全能力的港股市场适配；后续设计、实施与发布门槛以 [港股完整研究能力设计](2026-10-22-hk-market-full-design.md) 为准。本文保留作历史决策背景，不再作为当前功能边界。

## 目标

通过设置中的“股票市场”选项切换 A 股与港股上下文。港股 MVP 支持港股证券列表与搜索、加入自选、行情报价和日 K 观察；A 股现有流程保持原样。未适配港股的选股、回测及 A 股专属分析在港股上下文中明确显示暂不可用，不得展示 A 股结果。

## 市场上下文与代码

- 设置值为 `cn` 或 `hk`，默认 `cn`，使用现有工作区存储持久化。
- 切换市场后清除当前选中股票及其页面结果，按新市场重新读取状态，避免旧市场结果残留。
- 港股内部代码统一为五位数字加 `.HK`，例如 `00700.HK`；腾讯请求代码由适配器转换成 `hk00700`。
- 自选列表允许同时保存不同市场的代码；当前市场仅显示并操作本市场标的，切回后原自选项仍在。

## 数据来源与处理

- 以港交所当前证券清单作为港股证券主表来源，筛选普通股并保存代码与名称；不通过枚举代码段伪造证券池。列表刷新失败时保留最后一份有效缓存，并显示列表来源和更新时间。
- 沿用现有腾讯 HTTP 行情服务获取港股报价和日 K。行情请求、代码转换和字段解析集中在独立的港股数据适配层，避免把 HK 语义混入 A 股刷新逻辑。
- 港股报价解析单独处理 HKD、成交股数和成交额，保留来源、报价时间与原始单位；禁止复用 A 股的手数及金额倍率。
- 港股行情缓存使用独立文件和 schema，键采用规范化港股代码；缓存状态包含证券主表更新时间、行情来源、报价时间和历史 K 线覆盖。
- 页面展示币种、单位、数据来源与时间。网络请求失败时展示带来源的错误；有旧缓存时可展示并标明过期状态。任何失败都不得跨市场回退。

## 页面行为与范围

- 设置中的“股票市场”选择器启用“A 股”和“港股”，移除“即将上线”状态；选择器描述与可用功能相符。
- 港股市场提供普通股列表/搜索、自选操作、当前报价和日 K 观察。观察页只呈现该 MVP 有真实数据支持的行情信息，不调用 A 股财务快照或 A 股专属指标。
- 港股模式下，选股、回测和依赖 A 股指数/财务快照的功能显示简短的暂不可用说明，并保留返回 A 股的切换入口。
- A 股市场继续使用当前股票池、筛选、观察与回测实现；不改动既有行情和单位语义。

## 错误与缓存

- 缓存结构或行情解析不符合预期时，拒绝写入本次数据并保留最后有效缓存。
- 单只证券报价或历史 K 线缺失时显示该证券的具体缺失状态，不以零值、A 股数据或代理价格补齐。
- 证券清单、报价和历史数据分别记录来源及更新时间，方便判断局部失败和数据陈旧。
- 网络数据调用设置超时；测试使用固定响应样本，不要求在线行情服务可用。

## 验证

- Rust 单元测试覆盖港股代码规范化/腾讯代码转换、证券清单解析、HKD 报价单位、港股成交股数、报价时间及日 K 字段。
- 缓存测试确认 HK 与 CN 数据隔离、坏响应不覆盖有效缓存、港股缺数时不回退到 A 股数据。
- 前端测试覆盖设置持久化与切换、结果清理、自选市场过滤、港股可用页面和未开放页面状态。
- 运行相关 Rust 与前端测试及桌面构建；不以一次 live endpoint 请求代替 fixture 测试。
