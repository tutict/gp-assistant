# 选股研究、PIT 数据和冻结参数

当前固定策略为 `adaptive_swing_v1`，评分修订为 `unit-rank-fix/v1`，参数 ID 为 `fixed-v1`。修正版使用明确的百分比单位、原始收益的行业平均并列排名和小样本收缩；行业代码排序不会影响分数。校准版为 `adaptive_swing_v2`，只有本机研究工具生成并验证通过的冻结参数才可启用。

## 数据和单位

股票接口的 ROE、股息率、涨跌幅、换手率为比例值；扣非利润增速和净利率为百分点。财务接口的百分比指标为百分点。`mobile-financial-snapshot/v4` 明确记录 `metric_units`，股票记录另有 `stock_metric_units`。比例值 `1.2` 表示 120%；百分点 `0.804352` 表示 0.804352%，不能依靠大小推断单位。已知 v3 财务快照可按固定声明迁移；来源不明的财务快照须补齐单位。迁移不改变数据观测日期。

PIT 文件格式、完整 CSV 表头、时点规则和已支持公司行为见 [gp-research](../native/gp-research/README.md)。真实数据需要包含历史上市/退市证券、真实交易日、实际披露及修订记录、每日身份和可买卖状态、原始 OHLCV/股本以及公司行为。单期财务快照或当前股票池不能替代这些资料。

研究工具只读取本地包，校验清单与文件 SHA-256，使用独立 SQLite 保存原始 PIT 数据。禁止使用当前报表回填历史，日期不明确的披露保守地从下一交易日生效。停牌不删除持仓；无报价不伪造成交；分红、送转、拆股和结算按事件记录计入持仓及净值。未知或不完整的公司行为阻止严格验证。

## 本地研究工具

```powershell
cargo build --manifest-path native/gp-research/Cargo.toml --features cli --bin stock-research
.\native\gp-research\target\debug\stock-research.exe --help
```

工具提供 `import`、`validate`、`evaluate`、`calibrate`、`promote`、`rollback`。每次显式提供 `--app-data-dir`；应使用应用“设置 → 选股研究与验证 → 研究数据目录”显示的目录。详细参数及示例以 `--help` 和工具 README 为准。

1. `import --bundle` 导入准备好的文件包，记录返回的 `dataset_id`。
2. `validate --dataset` 检查目录、行情、披露、状态、事件和必要慢因子覆盖。
3. `evaluate --dataset` 运行冻结策略；`--parameters fixed-v1` 是修正后的固定权重主对照。指定不同参数只能用于其对应数据和实现。
4. `calibrate --dataset` 划分训练、验证和锁定测试区间，生成候选权重、诊断和最终门槛报告。
5. `promote --run` 只有完整、真实、通过验证并具有校准工具原生凭证的运行才可变更默认参数。
6. `rollback --parameters fixed-v1` 恢复当前修正版固定权重；还可恢复与当前实现匹配的既往已验证参数。

标准输出是 `{ok, command, data}` 或结构化错误，进度在标准错误。结果可重定向保存为 JSON。退出码区分成功、运行错误、数据或配置不合格、性能门槛未满足。合成样例只用于软件测试；它不能取得真实数据资格。

## 划分与启用门槛

本轮默认锁定测试期为 2021-10 至 2026-09，共 60 个完整月份；此前 12 个月用于验证，更早数据训练至少 36 个月。边界隔离 31 个交易日，10/20/30 日标签不跨区间用于调参。测试之前固定最终参数；测试结果不能反过来重选权重。未成熟标签和短数据如实报告，不缩短区间以制造通过结果。

仅校准既有震荡、趋势、防守权重。原本为零的因子保持为零，其余系数相对基准至多 ±0.05，和为 1；过热扣分至多 ±0.02。搜索最多 20 轮，每步 0.01，训练目标以 20 日 RankIC 为主并惩罚偏离。状态样本不足时保持固定权重。

启用须同时满足数据及身份完整、至少 60 个完整样本外月份、相对固定权重净年化增益至少 1 个百分点、回撤恶化至多 0.5 个百分点、换手至多增加 10%、10/25/50 bps 下候选池超额收益为正、至少 60% 的完整年度窗口超额为正、配对六个月分块 bootstrap 的 95% 下界为正，以及实际本地 PIT 重放的 20 秒冷运行/2 秒缓存门槛。重合率仅用于诊断，不强迫增加换手。

每份证据绑定原始数据、核心、研究工具和参数指纹。实现或数据变化后旧凭证不能自动沿用。手工写入 `passed=true` 不构成校准凭证。没有通过资格的参数不能进入普通选股请求。

## 应用与存储

“设置 → 选股研究与验证”只读取本地数据集摘要、运行报告和当前参数。批量导入、校准、启用与回退由命令行执行。结果进入回测时携带同一参数与数据集身份；未知、过期或身份不一致时明确报错。

校准版筛选使用冻结 PIT 数据的财务和历史状态，而不是当前缓存的估算指标；页面展示真实截至日期。PIT 未覆盖新增交易日时需要更新资料，不能把历史筛选称为实时结果。

大数据位于应用目录 `stock-research/datasets/<dataset_id>/dataset.sqlite`；轻量摘要、报告、参数与启用记录位于 `stock-research/research.sqlite`。应用读取不会建库或迁移。WAL 异常需由授权写入工具恢复；读取不能忽略未合并数据。Android 仅查看轻量记录，不在设备上执行批量校准。

这些是研究和软件验证工具；实际收益验证必须等完整、可靠的真实 PIT 数据到位后执行。软件测试通过不代表选股策略已经取得超额收益。
