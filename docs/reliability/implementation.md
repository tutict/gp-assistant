# 股选优客户端可靠性实施记录

更新：2026-10-07。分支：`codex/client-reliability`。未提交、未发布安装包；原有 `.deepeval/` 未修改。

## 当前状态

**主要加固已集成，但整份计划尚未全部完成，也不构成发布就绪证明。** Windows 与 Android 共用现有 Tauri/Rust/React 架构，没有引入云同步、遥测后台、自动更新或离线大模型。

## 已落地的代码

| 领域 | 当前实现 |
|---|---|
| 耐久写入 | 同目录唯一临时文件、校验、sync、平台替换；SQLite FULL/WAL；一致性迁移快照；现有损坏/空文件不伪装成新库 |
| 自选股 | 有序增量操作、修订号、重复操作回执、一次性迁移、丢失确认后的重新读取、保存状态与单项撤销；v2 pristine 标记用于安全恢复 |
| 研究资料回滚 | 阶段日志、递增代次、校验和、检查 checkpoint；旧资料配当前用户状态；不复活删除会话；不可用引用保留历史摘录 |
| 版本兼容 | 本地研究库 v3 独立于 v2 同步包；v2→v3 先备份再事务迁移；未来版本拒绝写入；v1/v2 资料包仍兼容 |
| 密钥 | Windows Credential Manager / Android Keystore；前端仅存引用；失败的旧明文迁移保留原字节且可重试；新密钥失败只留内存 |
| 加密备份 | Argon2id + AES-GCM；一致性 SQLite 数据导出、密码/篡改校验、恢复预览；自选股缺失/全新库恢复、Agent 账本 current-wins 合并与防重复回执 |
| 离线研究 | 筛选/观察/回测默认 cache_only；补数显式 refresh；缺数据报明细；返回时间与覆盖元信息；不换算法、不放松 PIT |
| 原生任务 | 行情、回测、资料包导入、FTS 重建接入状态/取消；实际阻塞线程结束后释放资源；网络与关键用户数据保存分开限流 |
| 工作区 | 页面、股票、筛选条件、回测参数/规格、会话与草稿进 SQLite；350ms 自动保存、显式重试；不自动发送或执行恢复的参数 |
| 退出与异常 | Windows 单实例；局部渲染错误边界；正常关闭先等待工作区/自选股保存，失败须确认放弃；未确认或仍有任务的退出不记为 clean |
| 移动端/资源 | 更低默认并发；退后台取消后续刷新批次；导入哈希/快照复制流式处理；完成请求清理取消监听器 |
| 诊断与门禁 | 本地白名单事件及任务结果计数、主动预览导出、GEPA 持久开关/安全启动；同设备同数据集 10% 门禁，不伪造缺失读数 |

## 已验证与证据

- 测试日志保存在 `tmp/reliability-*.log`；最终命令与结果见本次交付回复。早期轮次不是最终验收依据。
- `node scripts/reliability-ui-check.mjs`：真实 Chromium，1440×900 与 390×844；测试草稿失败/重试、重建页面恢复、回测参数、设置开关、诊断预览、无自动提交/页面错误/横向溢出。浏览器预览使用受限 localStorage 适配；Tauri 正式端仍使用 SQLite。**原生 IPC 为隔离模拟，不等于真机测试。**
- 浏览器证据：`tmp/reliability-ui/report.json` 与对应 PNG；完整前端套件的 82 个测试文件/530 个测试、构建、对比度、视觉交互和视觉基线检查均已通过。
- 原生测试使用临时目录，覆盖提交阶段子进程退出、WAL busy、旧回滚保留新状态、重复操作、迁移、损坏、密钥假后端、备份篡改、取消及工作区。未操作真实用户密钥/数据库。

## 尚未完成的代码范围（不是仅待测试）

1. **完整用户数据恢复**：研究、情绪、client-state 目前可加密导出、预览和隔离暂存，不能自动恢复/合并回活动库；UI 明确显示未恢复。跨库原子恢复和统一损坏恢复向导尚未实现。
2. **完整任务覆盖**：PDF/URL 导入、向量重建等仍使用原有有界工作线程，不在新的四类任务账本中。任务结果不做任意断点续跑。
3. **长期维护**：研究恢复快照暂不自动 GC；自选股操作回执保留；任务账本 10,000 条上限会明确失败，需要后续安全归档/回执退休设计，不能擅自删回执导致重放。
4. **性能深挖**：没有完成全量长列表分页/虚拟化、真实冷启动/内存/能耗基线采集。门禁已实现，但没有实测改进百分比。

## 发布前仍需验收

- 实际 Windows 凭据库及已安装 Android Keystore 的保存、拒绝、损坏、重启；当前测试不读取真实凭据。
- 真机强杀、Activity 重建、后台限制、磁盘满、断电/文件系统耐久性；子进程退出测试不能替代断电测试。
- 同签名升级与打包安装、关闭握手的真实 WebView 验收、全套历史 UI 基线；未运行完整发布打包流程。
- 真实同设备性能基线文件；缺失数据时门禁必须保持未验证。

## 关键裁决

- 保留当前工作目录，在独立分支实施；没有创建额外 worktree。
- 不安全的恢复拒绝执行，不用整库覆盖来冒充恢复成功。
- 旧明文迁移失败不删除原记录；成功验证系统存储后才移除。
- 会话超过存储容量时明确失败并保留内存，不截断后显示已保存。
- 分析/源代码审阅补齐了子代理中断后的集成；各 delivery 文档是历史记录，本页为当前状态。
